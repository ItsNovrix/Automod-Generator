About This Project

A behind-the-scenes look at Automod Generator.

The Tool Every Moderator Wishes They Had From Day One

Remember RedditAutomod.com? If you’ve been moderating on Reddit for more than a few years, you probably used it. It was the go-to utility that kept automod configuration straightforward, saving countless hours of headaches. When the original site went dark, it left a massive hole in the moderator toolkit.

This project is the spiritual revival of that exact tool—rebuilt from the ground up, modernized, and kept completely free for the community that needs it.

Built for Moderators

Let’s be honest: writing Automod code can feel like trying to defuse a bomb blindfolded. One misplaced space or rogue indentation ruins the entire block, and debugging YAML errors at 2:00 AM while a brigade is happening is nobody's idea of a good time.

This generator was revived to strip away the friction so you can actually focus on running your community.

Open Source & Transparent

We believe moderation tools should belong to the community. That’s why this project is fully open source.

If you're technically inclined, you can inspect the code, verify how it handles data, suggest improvements, or even self-host it. We have nothing to hide because this tool exists for one simple reason: to help the Reddit moderation ecosystem thrive.
