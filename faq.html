Frequently Asked Questions

Everything you need to know about Automod Generator.

What is Automod Generator?

Automod Generator is a free, open-source utility designed to make writing Reddit AutoMod configurations effortless. Instead of struggling with YAML syntax, spacing, and trial-and-error, you select the rules you want, and the generator builds clean, working code ready for you to copy and paste.

Do I need to log in or connect my Reddit account?

Not at all. Account connection or integration is not necessary to use this tool. You can use the generator anonymously, grab your code, and paste it straight into your subreddit's AutoMod page without handing over any permissions or data.

Is my subreddit data tracked or stored?

We don’t track you, run targeted ads, or store your configuration data. Because the project is fully open source, you can audit how the code handles everything yourself. Privacy and security are non-negotiable when you manage communities.

How do I apply the generated code to my subreddit?

Once you generate your rules on the site, follow these quick steps:

  1. Click the Copy button on the generated code block.
  2. Head over to your subreddit on desktop and go to your Mod Tools.
  3. Navigate to Automod under the moderation settings.
  4. Paste the code into your configuration file and hit Save.

Can I contribute or self-host this tool?

Yes! The project is open source. If you want to review the source code, suggest features, report bugs, or run your own instance, check out our repository linked on GitHub or stop by r/NovrixApps.
